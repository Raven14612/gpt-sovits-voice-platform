# 产品设计与使用流程

## 定位

产品把长音频到音色、音色到合成语音的流程组织成一个本地工作台。GPT-SoVITS 负责底层模型能力，平台负责输入整理、任务编排、校验、档案和成品管理。当前支持范围为 Windows / NVIDIA RTX 50 系 MVP。

产品将“音色文件组”与“语音成品”作为两类独立资产：前者是 GPT 与 SoVITS 权重及训练材料的组合，后者是可直接播放、下载和管理的最终 WAV。

## 五个页面

| 页面 | 输入与主要操作 | 输出 |
|---|---|---|
| 音频数据处理 | 导入、试听、命名保存、选择保留范围、切分和识别、确认标注 | 数据集、切片、标注和情绪标签 |
| 音色训练与仓库 | 提取特征、填写音色名称、训练、查看档案、管理回收站 | 可复用的音色文件组 |
| 文本生成语音 | 选择音色、中文文本、情绪和语速 | 已校验的合成 WAV |
| 合成结果管理 | 搜索、试听、改名、备注、下载、删除、复用参数 | 独立成品仓库 |
| 任务与日志 | 选择任务、查看阶段、状态和错误 | 运行反馈与故障定位信息 |

流程为：导入长音频 → 切分与识别 → 确认标注 → 特征提取 → GPT/SoVITS 训练 → 音色归档 → 文本合成 → 成品管理。

校对编辑区默认收起，允许直接采用识别结果，但仍需点击“确认标注并用于训练”。特征提取只准备模型输入，不产生音色权重。修改标注后，旧特征不能继续作为有效训练输入。

## 资产交互

- 数据集、标注版本、音色和成品支持中文显示名称；内部使用稳定 ID，改名不破坏关联。
- “我的音色”用于选择、查看档案和移入回收站。回收站用于恢复已选项目或彻底删除音色组及材料；删除前展示目标及清理范围并要求确认。
- 同一数据集再次用于独立音色组时，按归属规则复制训练材料，避免删除其中一组损坏另一组。
- 成品保存生成时的音色名称、来源数据集和参数快照。搜索包含成品名称、文本、音色、来源数据集及备注，无须原音色仍然存在。
- 删除原音色后仍可管理既有成品；再次生成时需改选可用音色。删除已下载到平台外的副本由用户自行管理。

## 界面原则

左侧固定五页导航，右侧宽度保持一致，并预留浏览器滚动条空间。统一米白纸面、砖红强调和深咖描边；不可编辑的状态区采用灰纸色和内框，避免与输入框混淆。

选定按钮在指针停留于按钮内约 2 秒后显示帮助气泡；按钮内移动不重新计时，移出后消失。按钮与说明的维护清单见[界面按钮功能清单](../界面按钮功能清单.md)，实际提示资源位于 `assets/button-hints.json`。

顶部进度条共用于五页，长页面滚动时保持可见。阶段来自真实任务，动画只表示等待：最多推进至约 93%，成功后填满，失败或取消停止。不会把动画长度作为训练时长或 GPU 利用率。

## 能力边界

GPU 工作串行；不提供后台并行训练或自动断点续训。语音合成接受 1–500 字的中文文本，情绪限于所选音色已有的参考条目，语速范围为 0.5–2。当前推理接口不支持可调句间停顿，界面保留禁用说明。

环境检查只能说明本机准备状态，不能替代真实训练、合成和人工听测。第三方模型效果受输入音频、文本、标注和训练样本影响。
