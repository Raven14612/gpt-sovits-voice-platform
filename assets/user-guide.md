# 小渡鸦的语音合成平台 · 使用说明

把一段中文变成可播放的语音，或用自己的录音训练一个音色。本说明按页面上的实际按钮编写，适用于当前 Windows / NVIDIA RTX 50 系 MVP 版本。

**已经有可用音色？** 从「第一次合成」开始。**想训练自己的音色？** 按「准备音频」「校对标注」「训练音色」依次操作。左侧导航可以随时切换页面；任务执行期间可打开本说明查阅。

## 1. 启动与准备

将完整运行包解压到一个固定目录，双击 `start.bat`，浏览器会打开工作台。只拿到源码包时，需要先按随包的环境准备说明安装运行资源。不要在压缩包内直接启动。

查看左侧「环境状态」。如果提示缺少解释器、模型或资源，先按提示补齐。需要完整检查时，在程序目录打开终端运行 `./start.bat --diagnose`，保留检查结果供排查。

界面里的三个常用名称：

- **数据集**：保存的原始音频，以及随后生成的切片、识别文字和标注。
- **音色文件组**：训练得到、可以反复用于合成的音色。平台会一起管理所需的 GPT 与 SoVITS 模型文件。
- **成品**：用某个音色生成的 WAV 音频，可以试听、改名和下载。

当前 GPU 任务依次执行。切分识别、提取特征、训练或合成正在占用 GPU 时，请等待当前任务结束，再提交下一项。执行期间保持电脑运行，不要关闭启动程序或让电脑休眠。

## 2. 第一次合成

1. 点击左侧「文本生成语音」，在「选择音色」中选一个可用音色。列表为空时，先训练音色，或到已连接的工坊安装音色。
2. 在「要生成的文字」中输入 1–500 字的中文文本。第一次建议用一两句完整短句，例如：今天的天气很好，我们一起出去走走吧。
3. 选择该音色提供的情绪。`neutral` 表示普通，`happy` 表示高兴，`sad` 表示悲伤；可选项由音色已有的参考音频决定。
4. 如需调整，展开「高级设置」。语速默认为 `1.0`，小于 1 更慢，大于 1 更快，范围为 `0.5–2.0`。「句间停顿」目前不能调整。
5. 点击「合成语音」，等待显示成功。平台会保存成品并切换到「合成结果管理」。点击播放器试听，检查读音、漏字和语气，再下载满意的版本。

生成效果受音色素材、文字和参考情绪影响。若长句读得不自然，可先缩短句子、补齐标点，用短文本比较不同设置。

## 3. 准备音频与切分识别

建议选用同一说话人、声音清楚、背景音乐和噪声较少的录音。先试听，排除长时间空白、多人重叠说话和明显失真的部分。只使用你有权处理的素材。

1. 打开「音频数据处理」，在「导入音频」中上传 **PCM WAV** 文件，并用「上传音频试听」检查内容。MP3 等文件需要先转换；仅修改扩展名不能转换格式。
2. 填写「数据集名称（支持中文）」，例如“朗读素材第一批”，点击「保存音频」。确认「当前数据集」已选中刚保存的项目。
3. 设置「保留起点（秒）」。默认勾选「保留到音频结尾」；只处理其中一段时，取消勾选，再填写「保留终点（秒）」。这些时间以原音频开头为起点，终点应晚于起点。
4. 点击「切分并识别」。平台会处理选定范围、生成短音频切片并识别文字。等待任务成功，再继续确认标注。

已有数据集可从「当前数据集」重新选择；列表未更新时点击「刷新数据集」。要改名，在「修改数据集名称（支持中文）」中输入新名称，再点击「保存数据集名称」。

## 4. 校对文字与确认情绪

识别结果没有需要修改的地方时，可以直接点击页面底部「确认标注并用于训练」。未设置情绪的切片默认为普通。**这一步必须完成，数据集才能进入训练准备。**

需要修正时，展开「识别与人工校对（可选）」：

1. 在「切片标注」表格中选择一行。
2. 修改下方「校对文本」，让文字与这一段录音一致；再选择「人工情绪标签」。不要直接在只读表格中输入。
3. 点击「更新切片」，把这一行的修改更新到表格。继续检查其他行。
4. 可填写「标注版本名称（支持中文）」以便辨认，然后点击面板外的「确认标注并用于训练」，正式保存。

**智能情绪建议是可选功能。** 点击「重新检测模型」，确认情绪模型可用后，可点击「智能标注未确认项」，查看每条建议的类别、置信度和复核说明。「接受高置信度建议」可以批量采用部分建议，最后仍要确认标注。模型只分析文字语义，不能判断录音中的真实语气；拿不准时优先按实际音频人工选择。

没有情绪模型也能人工标注、训练和合成。「导入已有识别文本」用于导入与当前切片匹配的 `.list` / `.txt` 标注；首次使用无需填写。「导出中文名称标注」可生成可下载的标注文件。

重新修改并确认标注后，需要重新提取特征，不能继续沿用旧版本的训练特征。

## 5. 训练音色

1. 进入「音色训练与仓库」，选择「待训练数据集」。若列表尚未更新，点击「刷新音色与数据集」。
2. 点击「准备训练数据（提取特征）」，等待准备成功。这一步把音频与标注转换为训练输入，还没有生成新音色。
3. 填写「音色文件组名称（支持中文）」，使用容易辨认的名称，例如“朗读音色第一版”。
4. 点击「开始训练并保存音色」。平台依次训练所需模型并保存音色，耗时取决于素材量和电脑性能。
5. 任务成功后，在「我的音色」中选择新音色，点击「查看档案」检查信息，再到「文本生成语音」用短句试听。

按钮不可用时，先查看页面提示：是否选中了数据集、是否已确认标注、特征是否已完成，以及是否还有其他 GPU 任务正在执行。训练失败后请先查明原因，再重新提交；重启程序不会自动断点续训。

## 6. 管理音色和成品

### 音色仓库

在「音色训练与仓库」的「显示音色」中选择音色，可查看档案或「移入回收站」。移入回收站后，这个音色暂时不能用于合成，但可在「已删除音色」中选择它，点击「恢复已选项目」。

「彻底删除」会先展示清理范围，确认后清除音色组及关联训练材料。操作前仔细核对目标。已生成的成品独立保留，不会随来源音色一起删除。

### 合成结果管理

- **查找与试听**：用名称、生成文本、音色、来源数据集或备注搜索，再从生成记录中选择成品。
- **改名与备注**：填写「成品名称（支持中文）」和「备注」，点击「保存名称与备注」。
- **下载**：点击「准备中文文件下载」，待「下载成品」出现文件后点击下载；也可使用播放器的下载按钮。
- **再次生成**：点击「复用参数」，文本、情绪和语速会回填到合成页。检查后再点击「合成语音」，不会自动生成。原音色已删除时，需要另选可用音色。
- **删除**：「删除结果」用于移除平台里的该条成品。重要音频请先下载保存；这项操作没有音色回收站那样的恢复入口。已下载到平台之外的文件不会被一起删除。

## 7. 使用音色创意工坊

工坊用于分享和安装音色。它需要部署者提供可用的服务地址；本地训练与合成在你的电脑上进行，工坊连接失败不影响已准备好的本地功能。

### 浏览与安装

1. 打开「音色创意工坊」，查看「服务地址」和「工坊状态」。可点击「测试连接」排查连接，点击「刷新列表」更新条目。
2. 用「搜索名称或作者」查找音色。鼠标移到卡片上或用键盘聚焦卡片，可看到操作按钮；触屏设备直接显示操作。
3. 点击「查看详情」，阅读作者、简介和许可。点击「安装模型」后，核对来源与许可，勾选确认并执行安装。
4. 等待提示「安装成功」，再到「文本生成语音」选择该音色。安装成功表示资源已就绪，实际发声效果仍需合成并试听。

已安装的卡片提供「卸载模型」，确认后移入本地音色回收站。再次点击安装可按提示恢复。卸载只改变本机安装状态，不会撤下工坊中的共享条目。

### 上传与维护自己的条目

展开「上传本地音色」，选择本地可用音色，填写作者、简介和许可；确认你拥有分享该音色、权重及参考音频的权利。远程服务需要上传令牌时，向部署者取得并填写，然后点击「上传选中音色」。上传状态会显示校验、打包、上传和最终结果；成功后列表自动刷新。

上传者可在自己的「查看详情」弹窗中展开「设置封面」，上传 PNG、JPEG 或 WebP 图片（最大 4 MiB），然后保存。

若要停止新的公开下载，在本人条目详情中展开「下架我上传的音色」，勾选确认后点击「确认下架」。下架后条目退出公开列表，服务器保留存档，各客户端已经安装的副本仍可使用。上传者身份保存在本机平台数据中；换一份全新数据目录不会自动继承原来的管理权限。

## 8. 查看进度与处理问题

顶部进度条显示当前任务阶段。动画表示仍在等待，不是实际完成百分比，也不是剩余时间预测。只有任务真正成功后才会填满。

到「任务与日志」点击「刷新任务列表」，从「已保存任务」中选择对应任务，查看状态、阶段和日志摘要。排查时记录错误码、失败阶段以及提示中的日志文件位置。

### 启动后没有可选音色

平台不会把任意模型文件夹自动识别为音色。先完成训练，或通过工坊安装；如果音色在回收站，先恢复，再刷新音色列表。

### WAV 文件无法导入

确认它是可正常播放的 PCM WAV，而不是改过后缀的其他格式；重新导出为 PCM WAV 后再试。

### 训练按钮不可用，或提示特征无效

回到「音频数据处理」确认当前标注已经保存，再选择同一数据集完成特征提取。修改过标注时重新提取；有 GPU 任务运行时等它结束。

### 进度长时间停在一个阶段

先查看日志是否仍有更新。模型加载、特征提取和训练所需时间不同，不能仅凭进度条位置判断卡住。如果任务已失败，按错误提示处理资源缺失、显存或文件问题，再重新提交，避免连续重复点击。

### 合成失败或听起来不理想

检查音色是否可用、文本是否为 1–500 字、所选情绪是否有参考音频。若任务成功但效果不好，先用短句、默认语速和普通情绪比较，再检查训练素材及文字标注。生成成功不等于读音和音质一定符合预期。

### 工坊没有内容或无法连接

先清空搜索词并刷新；空列表也可能表示服务里尚未有人上传。连接失败时检查「服务地址」，联系部署者确认服务和网络可用。无需为此反复重训本地音色。

### 程序意外退出

重启后查看任务与日志以及恢复提示。被中断的任务不会自动重放或续训，请确认状态后重新提交。已有音色和成品可从各自页面重新选择。

## 9. 保存与备份

音频、数据集、音色、成品和索引统一保存在程序目录的 `data/` 中。备份前先等待任务结束并退出程序，再成套备份 `data/` 和 `config/` 中的本地配置；只复制某个模型文件或成品文件，不能完整恢复整个工作台。

升级或搬动程序目录前先备份。不要用新包中的空数据目录覆盖自己的数据。只想保存最终音频时，直接从「合成结果管理」下载；想继续训练、管理音色或保留工坊上传身份时，应保留完整数据备份。

阅读完毕后，可点击右上角「关闭」、按 Esc，或点击弹窗外的遮罩，回到刚才的页面。
