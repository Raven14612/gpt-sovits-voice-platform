# 小渡鸦的语音合成平台哟

基于 GPT-SoVITS 的本地语音工作台：导入长音频、切分识别、确认标注、提取特征、训练音色，再使用音色合成并管理语音成品。界面采用米白与砖红的统一复古配色。

**MVP：当前面向 NVIDIA RTX 50 系 Windows 电脑。** 每台电脑仍须通过环境检查；其他平台和显卡尚未纳入支持范围。使用有权处理的音频和模型。

## 启动

在项目根目录双击 `start.bat`，浏览器会自动打开。已有同一实例时复用该实例；不会终止未知端口占用进程。

```powershell
./start.bat --check                 # 检查路径和解释器，不启动界面
./start.bat --diagnose              # 完整环境诊断，不启动界面
./start.bat --port 17860            # 使用其他界面端口
```

启动使用包内 `runtimes/ui/python.exe`；模型使用独立的 `engines/verified-v2pro/runtime/python.exe`。源码仓库不等于已包含模型和运行时的完整运行包。缺少环境或资源时，按[环境准备说明](setup/EnvironmentSetup/PREPARE.md)操作，再运行[环境诊断](setup/EnvironmentSetup/README.md)。

## 使用流程

1. **音频数据处理**：上传 PCM WAV、试听、填写数据集名称并保存；选择保留范围，点击“切分并识别”。识别结果满意时直接“确认标注并用于训练”；需要修改时展开可选校对区。
2. **音色训练与仓库**：选择已确认的数据集，提取特征，再填写音色名称并训练。成功后归档 GPT 与 SoVITS 两个权重，作为一个音色文件组管理。
3. **文本生成语音**：选择音色、输入中文文本，选择该音色支持的情绪并合成。语速可调；当前引擎不支持调整句间停顿。
4. **合成结果管理**：搜索、试听、改名、写备注、下载、删除成品，也可复用生成参数。成品独立保存，删除原音色组不会删除已生成语音。
5. **任务与日志**：查看任务状态、阶段及错误详情。顶部模拟进度条显示当前阶段，只有实际成功才填满；它不是实际完成百分比或耗时预测。

GPU 任务串行执行。发生错误先查看状态说明和日志；应用重启不会自动续训或重放中断任务。

## 目录与备份

| 目录 | 用途 |
|---|---|
| `ui/`、`assets/` | Gradio 页面、主题和按钮提示 |
| `services/`、`adapters/`、`models/` | 业务编排、引擎适配和数据结构 |
| `config/` | 配置模板、依赖锁定和资源清单；本地配置单独维护 |
| `data/` | 用户数据集、音色、成品、索引及运行日志 |
| `setup/EnvironmentSetup/` | 环境诊断与配置工具 |
| `scripts/`、`tests/` | 启动、迁移和验证工具 |
| `third_party/`、`engines/`、`runtimes/` | 第三方源码、模型资源和独立运行时 |

备份前停止任务并退出应用，成套备份 `data/` 和本地配置。升级或搬目录前先备份，在副本中执行[迁移流程](Documents/开发与交付.md)。向他人分发时使用明确的交付清单，不直接压缩整个开发目录。
