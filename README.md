# 小渡鸦的语音合成平台哟

当前交付版本：**Final-MVP1.0**。完整运行包已包含应用源码、包内解释器、GPT-SoVITS v2Pro 训练与合成资源以及离线情绪模型，可解压后直接双击 `start.bat` 启动。

基于 GPT-SoVITS 的本地语音工作台：导入长音频、切分识别、确认标注、提取特征、训练音色，再使用音色合成并管理语音成品。界面采用米白与砖红的统一复古配色。

**MVP：当前面向 NVIDIA RTX 50 系 Windows 电脑。** 每台电脑仍须通过环境检查；其他平台和显卡尚未纳入支持范围。使用有权处理的音频和模型。

## 启动

在项目根目录双击 `start.bat`，浏览器会自动打开。已有同一实例时复用该实例；不会终止未知端口占用进程。

```powershell
./start.bat --check                 # 检查路径和解释器，不启动界面
./start.bat --diagnose              # 完整环境诊断，不启动界面
./start.bat --port 17860            # 使用其他界面端口
```

启动使用包内 `runtimes/ui/python.exe`；模型使用独立的 `engines/verified-v2pro/runtime/python.exe`。`Final-MVP1.0` 完整运行包已包含这两套运行环境。缺少环境或资源时，按[环境准备说明](setup/EnvironmentSetup/PREPARE.md)操作，再运行[环境诊断](setup/EnvironmentSetup/README.md)。

## 使用流程

完整操作说明见[使用指南](assets/user-guide.md)，也可在任意页面底部点击「项目的使用帮助」打开阅读弹窗。

1. **音频数据处理**：上传 PCM WAV、试听、填写数据集名称并保存；选择保留范围，点击“切分并识别”。识别结果满意时直接“确认标注并用于训练”；需要修改时展开可选校对区。
2. **音色训练与仓库**：选择已确认的数据集，提取特征，再填写音色名称并训练。成功后归档 GPT 与 SoVITS 两个权重，作为一个音色文件组管理。
3. **文本生成语音**：选择音色、输入中文文本，选择该音色支持的情绪并合成。语速可调；当前引擎不支持调整句间停顿。
4. **合成结果管理**：搜索、试听、改名、写备注、下载、删除成品，也可复用生成参数。成品独立保存，删除原音色组不会删除已生成语音。
5. **任务与日志**：查看任务状态、阶段及错误详情。顶部模拟进度条显示当前阶段，只有实际成功才填满；它不是实际完成百分比或耗时预测。
6. **音色创意工坊**：连接共享音色库，浏览自己和他人发布的音色，下载并安装到本机；上传者可设置自己条目的封面。展开“上传本地音色”即可分享已验证音色。训练、合成及安装后的使用在本机进行，工坊不可用时不影响前五页。

最终部署为“本地工具 + 独立远程工坊服务”。启动和本地业务不连接工坊，进入工坊或执行工坊操作时才访问。默认关闭本机服务自动启动；正式共享部署需在 `config/workshop.local.json` 配置部署者提供的真实 HTTPS 地址，并保留 `auto_start_local: false`。本机开发联调可显式设置为 `true`，仍只在使用工坊时启动。远程目录由服务器管理，客户端通过 API 访问，无需挂载服务器文件夹。独立服务器与两台客户端的最终验收仍待外部环境提供。

卡片的“卸载模型”只把本机音色移入回收站；点击“安装模型”可恢复，未下载的音色则先确认许可再下载并安装。上传者可在“查看详情”中展开“下架我上传的音色”，勾选确认后撤下自己的远程条目，停止公开浏览、封面访问和新下载。服务器保留存档，不删除各客户端已经安装的副本。普通用户不能修改或下架别人发布的音色。完整产品边界记录在本地设计资料中。

本地工坊默认存储在 `data/workshop/`，如已有项目根目录下的 `workshop_data/` 则继续使用原目录。首次使用列表为空是正常情况，需要在页面上传 `.rvoice` 音色；普通模型文件夹不会自动变成工坊条目。 上传按钮下方显示等待、校验打包、上传和最终结果；处理期间按钮禁用，成功后清空搜索并自动刷新网格。点击卡片“查看详情”打开可关闭弹窗；上传者可以展开弹窗内的“设置封面”上传，可用 PNG、JPEG、WebP（最大 4 MiB）。修改封面不需要重新上传权重，封面保存在服务端，所有连接此工坊的用户都能看到。

连接问题：完全退出旧平台进程后重新双击 `start.bat`；本机 `8090` 端口被其他程序占用时不会强行终止该程序，可关闭占用程序或更改工坊地址端口。手动管理工坊服务时设置 `auto_start_local: false`。详见[工坊服务使用说明](workshop_server/README.md)。

### 情绪建议模型

切分识别后可在人工校对区点击“重新检测模型”。将发布者提供的 `emotion-zh-v1.zip` 解压到 `models/emotion/emotion-zh-v1/`，模型仅在 CPU 上运行并提供文本语义建议。建议必须人工确认后才进入 `emotions.json`，模型缺失时人工标注、训练和合成照常可用。

GPU 任务串行执行。发生错误先查看状态说明和日志；应用重启不会自动续训或重放中断任务。

## 目录与备份

| 目录 | 用途 |
|---|---|
| `ui/`、`assets/` | Gradio 页面、主题和按钮提示 |
| `services/`、`adapters/`、`models/` | 业务编排、引擎适配和数据结构 |
| `config/` | 配置模板、依赖锁定和资源清单；本地配置单独维护 |
| `data/` | 用户数据集、音色、成品、索引及运行日志 |
| `setup/EnvironmentSetup/` | 环境诊断与配置工具 |
| `scripts/`、`tests/` | 启动、迁移和验证工具 |
| `third_party/`、`engines/`、`runtimes/` | 第三方源码、模型资源和独立运行时 |

备份前停止任务并退出应用，成套备份 `data/` 和本地配置。升级或搬目录前先备份，在副本中执行本地迁移流程。向他人分发时使用明确的交付清单，不直接压缩整个开发目录。
