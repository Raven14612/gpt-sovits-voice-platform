- 计划不能写成已完成；完成状态必须有代码、日志、音频或截图证据。
- GPT-SoVITS 与第三方整合包是外部依赖，不属于本项目自研成果。

- 新文档优先修改现有文件，不再创建同义的 `newplan2`、`final-plan` 等文件。
