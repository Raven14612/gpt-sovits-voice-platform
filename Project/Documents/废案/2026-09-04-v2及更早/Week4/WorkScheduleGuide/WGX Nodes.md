主题精修与四态统一已由 **CXY** 承担（CXY-N2）。你只做两件不写代码、不需要对接的事：**浏览器兼容验证**与**录屏 / 终稿截图**。

## WGX-N1：浏览器兼容验证

**目标**  
确认答辩环境的浏览器能正常显示四页、播放与下载音频。

**输入**

- CXY-N2 终稿主题与四态标准。
- 可启动的集成版（含启动命令）。

**工作**

在 **Chrome 与 Edge** 各走一遍：

- 四页逐一切换，确认布局无错位、无溢出、侧栏高亮正确。
- 音频播放器可播放当前结果与历史条目。
- 下载 WAV 能落地并可本地播放。
- 检查缩放 100% 与 125% 下的布局。
- 记录控制台报错。

**输出**

- 浏览器兼容结论表（浏览器 / 检查项 / 结果 / 问题）。
- 问题截图（若有）。

**三个指标**

- **哪些人的工作会影响我？** 可启动的集成版是启动条件；CXY-N2 主题终稿是软依赖。
- **我需要交付什么内容？** 兼容结论表与问题截图。
- **谁需要等待我完成该工作？** 无人硬等待。CXY-N5 会核对；未交付时 CXY 自行完成。

**完成判定**

- Chrome 与 Edge 均有明确结论。
- 播放与下载各至少验证一次成功。
- 交付格式：`[WGX-N1] 结论表路径 + 一行结论 + 已发现问题`，无需等待回复。

**AI 参考提示词**

```text
检查项：

2. 音频播放器可播放当前结果与历史条目；
3. 下载WAV能落地并本地可播放；
4. 缩放100%与125%下的布局；

输出：逐项检查表（浏览器/检查项/期望结果/实际结果/问题）、问题登记模板与截图命名建议。
注意：我只登记问题，不修改代码。
```

## WGX-N2：录屏与终稿截图

**目标**  
按演示脚本产出答辩用录屏素材与终稿截图。

**输入**

- CXY-N3 的 8–10 分钟演示脚本与分镜、演示参数包。
- 可启动的集成版。

**工作**

- 按分镜录制演示链路的分段录屏（建议按 10 步链路分段，便于重录单段）。
- 录制时使用演示参数包中的音色与文本，不自行更换。
- 为四页各截 1 张终稿图，另截环境状态区、音色卡片墙、历史列表各 1 张。
- 按分镜编号命名文件，整理成一个目录并附一份索引表（编号 / 对应演示步骤 / 文件名 / 时长）。
- 不做剪辑创作与文案编写；如需字幕，只照抄脚本口播要点。

**输出**

- 分段录屏文件 + 索引表。
- 7 张左右终稿截图。

**三个指标**

- **哪些人的工作会影响我？** CXY-N3 演示脚本与参数包是启动条件。
- **我需要交付什么内容？** 分段录屏、索引表与终稿截图。
- **谁需要等待我完成该工作？** 无人硬等待。CXY-N5 会用于答辩材料；未交付时 CXY 自行录制。

**完成判定**

- 录屏内容与演示脚本步骤对应，参数未被自行更改。
- 截图为终稿界面，不是旧版或设计稿。
- 交付格式：`[WGX-N2] 素材目录 + 索引表路径 + 一行说明`，无需等待回复。

**AI 参考提示词**

```text

演示脚本与分镜：<粘贴CXY-N3演示脚本>

输出：

3. 索引表模板（编号/对应步骤/文件名/时长/备注）；
4. 需要的终稿截图清单：四页各1张 + 环境状态区 + 音色卡片墙 + 历史列表；
5. 录制前的检查项（分辨率、缩放、隐藏无关窗口、关闭通知）。

注意：我只按脚本录制，不更换音色或文本，不做剪辑创作与文案编写。
```
