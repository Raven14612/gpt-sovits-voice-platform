## LHY-N1：建立工程骨架

**目标**  
建立后续四周共用的单体 Gradio 工程和唯一入口。

**输入**

- `newplan.md` 建议目录。
- CXY-N1 模块边界；未交付时可先搭目录。

**工作**

- 建立 `app.py`、`ui/`、`services/`、`models/`、`assets/`、`data/`、`tests/`。
- `app.py` 建立最小 `gr.Blocks` 和 `queue()`。
- 不实现完整业务，不添加独立 API 或数据库。

**输出**

- 项目目录骨架。
- 可打开空白 Gradio 的 `app.py`。
- 最小依赖与启动说明。

**三个指标**

- **哪些人的工作会影响我？** CXY-N1 是软依赖；可先建立骨架，收到模块边界后再核对。
- **我需要交付什么内容？** 项目目录、`app.py` 和启动说明。
- **谁需要等待我完成该工作？** LHY-N2 硬等待；CXY-N5 软等待 `ui` 导入路径。

**完成判定**

- 一个命令能打开本地空白 Gradio。
- 没有第二套前后端工程。

**AI 参考提示词**

```text
请为本地Windows GPT-SoVITS项目设计最小单体Gradio工程骨架。

必须包含：
app.py、ui、services、models、assets、data、tests。
app.py只创建gr.Blocks、加载CSS、启用queue并启动。

限制：
- 不使用FastAPI、Vue/React、数据库、Redis或Celery；
- 不实现GPU业务；
- 不生成假音频；
- 不修改GPT-SoVITS上游。

输出目录树、最小app.py建议和启动检查清单。
```

**输入**

**工作**

- 建立四个 service 文件。

**三个指标**

- **我需要交付什么内容？** 可导入的 services、schema、错误结构和数据目录初始化。
- **谁需要等待我完成该工作？** LHY-N3 硬等待；CXY-N5 软等待状态字段。

**完成判定**

- 模块均可导入。
- 未实现函数返回明确错误，不返回假成功。

## LHY-N3：对齐算法 I/O、日志与桩函数

**目标**  
让 UI 能调用结构稳定的函数，并为 Week 2 保留正确接口。

**输入**

- LHY-N2 模块。
- CXY-N3 的环境基线记录与实际模型入口。
- CXY-N4 的 TTS 参数与切分/ASR 说明。
- CXY-N2 契约草案。

**工作**

- 对齐 TTS、切分和 ASR 输入输出。
- 添加日志和错误包装。
- 环境状态与空列表可返回真实结果。
- 未集成 GPU 的函数明确“未实现”，不返回假 WAV。

**输出**

- 结构稳定的 service 函数。
- 日志与错误示例。
- 给 WGX 的函数说明。

- **哪些人的工作会影响我？** LHY-N2 是硬依赖；CXY-N2/N3/N4 是软依赖，收到真实参数及契约后完成最终对齐。
- **我需要交付什么内容？** 稳定接口、日志、错误示例和 UI 调用说明。
- **谁需要等待我完成该工作？** LHY-N4 硬等待；CXY-N6 等集成返回结构。

**完成判定**

- 没有假音频或假成功。

## LHY-N4：集成 UI 与一键启动

**目标**  
将 CXY 交付的页面接入唯一 `app.py`，形成阶段演示壳。

**输入**

- LHY-N3 services。
- CXY-N5 的 `layout.py`、四页模块与 State。

**工作**

- 在 `app.py` 组装布局和四页。
- 确认侧栏切换、环境状态和错误显示。
- 保证不依赖第二个服务。
- 输出启动日志与说明。

**输出**

- 一键启动集成版。
- 启动日志。
- 给 CXY 的联调入口（WGX 据此做浏览器冒烟）。

**三个指标**

- **哪些人的工作会影响我？** LHY-N3 与 CXY-N5 都是硬依赖；两者完成后才能开始集成。
- **我需要交付什么内容？** 一键启动集成版、启动命令和日志。
- **谁需要等待我完成该工作？** CXY-N6 等预演；WGX-N1 等浏览器冒烟启动条件。

**完成判定**

- 一个命令打开页面。
- 四页切换可用，主区不出现 2×2。

**AI 参考提示词**

```text
请帮助集成单体Gradio入口。

输入：
- ui/layout.py和四个页面模块；
- services模块；
- 当前app.py。

要求：
- app.py唯一入口；
- 顶栏+左侧四项+右侧单页；
- 环境状态不是第五页；
- 使用gr.State；
- 启用queue；
- 显示真实AppError；
- 不启动第二个HTTP服务；
- 不绑定假WAV。

输出集成步骤、修改位置和启动/冒烟清单。
```
