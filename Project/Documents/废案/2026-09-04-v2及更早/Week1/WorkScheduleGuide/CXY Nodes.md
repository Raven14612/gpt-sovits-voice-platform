## CXY-N3：本机环境打通（P0）

**目标**  
把主 GPU 轨道的阻塞项清掉，使 GPT-SoVITS 能在本机真实运行。

> 本节点接管原 LJQ-N1。主轨为 **CXY 本机 RTX 5060 Laptop（Track B）**。

**输入**

- [GPU Environment Baseline.md](../../GPU%20Environment%20Baseline.md) 模板与双轨道说明。
- `env/LJQ-baseline.md` 已记录的 P0 阻塞项：PyTorch 未安装、预训练权重缺失、FFmpeg 不可用、ASR 模型缺失。
- `Reference-Project/GPT-SoVITS-main` 与 50 系整合包存档。

**工作**

- 建立符合 Track B 的 Python 环境（建议 Python 3.11 + PyTorch 2.7/cu128），确认 `torch.cuda.is_available()`。
- 补齐 GPT-SoVITS 预训练权重与至少一种 ASR 模型。
- 安装可用 FFmpeg，确认 `ffmpeg -version` 正常返回。
- 确认官方零样本推理入口可启动或可导入。
- 更新个人基线表与环境矩阵（矩阵改由 CXY 维护）。

**输出**

- `env/CXY-baseline.md`（主轨记录，命令输出为证据）。
- 环境矩阵 §6 更新。
- 剩余风险与显存约束说明（8 GB 显存需单任务串行）。

**三个指标**

- **哪些人的工作会影响我？** CXY-N1 是软依赖；环境工作可立即开始。
- **我需要交付什么内容？** 可复现的本机环境记录和实际启动方式。
- **谁需要等待我完成该工作？** 本人 N4 硬等待；LHY-N3 等模型路径与入口。

**完成判定**

- 版本全部来自本机命令输出，不是推测。
- PyTorch、权重、FFmpeg、ASR 四项均有明确“可用/不可用”结论。
- 任一项仍不可用时，必须在 `Decisions.md` 记录降级并给出对 N4 的影响。

**AI 参考提示词**

```text
我在Windows上打通GPT-SoVITS环境，本机为RTX 5060 Laptop（Track B，8GB显存）。
已知阻塞：Python 3.13无PyTorch、预训练权重缺失、FFmpeg不可用、ASR模型缺失。

请先阅读 Project/Documents/GPU Environment Baseline.md，再给出：
1. Track B建议的Python/PyTorch/CUDA组合与安装顺序；
2. 需要补齐的权重与ASR模型清单及放置路径；
3. FFmpeg可用性验证方法；
4. 官方零样本入口的启动或导入验证步骤；
5. 8GB显存下的单任务串行注意事项；
6. 每步应记录到基线表的字段。

不要猜测版本；所有结论由我运行命令后填写。不要执行来源不明的下载命令。
```

## CXY-N4：官方基线 WAV 与切分/ASR

**目标**  
证明本机能稳定出声，并产出 Week 2 音频业务所需的真实 I/O。

> 本节点接管原 LJQ-N2 与 LJQ-N3，合并执行。

**输入**

- CXY-N3 可运行环境。
- CXY-N2 的授权短参考、长音频与试听文本。
- 官方切分与 ASR 工具。

**工作**

- 用官方零样本流程生成 3 条 WAV，记录参考音频、提示文本、合成文本、参数、耗时、显存与错误。
- 真实执行一次官方静音/音量阈值切分。
- 真实执行一次 ASR，记录切片命名、转写结果和 `.list` 四字段。
- 对照 `contract-v0.1` 列出常见失败原因与建议错误码。

**输出**

- 3 条真实 WAV 与推理参数、日志。
- 一组真实切片与一份真实 ASR 输出。
- 算法 I/O 与失败条件说明（交 LHY）。

**三个指标**

- **哪些人的工作会影响我？** CXY-N3 是硬依赖；CXY-N2 是软依赖（可先用已有合法素材）。
- **我需要交付什么内容？** 3 条真实 WAV、切分/ASR 文件、参数表与失败条件。
- **谁需要等待我完成该工作？** LHY-N3 等调用结构与真实参数；本人 N6 等验收证据。

**完成判定**

- 3 条 WAV 均由本机本次运行产生且人工确认可播放。
- 切分与 ASR 文件实际存在且可打开。
- 明确为官方静音阈值切分，不冒充自研 VAD。

**AI 参考提示词**

```text
请基于我本地GPT-SoVITS源码，设计一次合并执行的基线方案：零样本TTS 3条 + 官方切分1次 + ASR 1次。

输入：
- 授权短参考：<路径>  参考文本：<文本>
- 试听/合成文本：<文本>
- 长音频：<路径>  输出目录：<路径>
- 契约草案：<粘贴contract-v0.1相关函数>

输出：
1. 基于当前源码的最小调用方式与必填参数；
2. 3次推理与1次切分/ASR的记录模板（含耗时、显存）；

不要编造API，不修改模型核心，不生成假ASR结果，不把示例音频当成功证据。
```
