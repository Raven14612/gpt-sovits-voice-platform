## 1. 使用方式

### 1.1 记录决议

每条决议一行，追加到 §3 表格，**不修改历史行**。需要修正时新增一行并在备注写「取代 D-00x」。

| 字段 | 说明 |
|---|---|
| ID | `D-001` 起顺序编号 |
| 日期 | 决议日期 |
| 主题 | 一句话概括 |
| 决议 | 拍板结论，必须可执行 |
| 影响 | 受影响的节点或文件 |
| 备注 | 取代关系、降级原因、待复核项 |

### 1.2 提交异议

LJQ / LHY / WGX 只能按下面格式提一条问题，追加到 §4：

```text
问题：<一句话>
影响：<一句话，说明会导致什么后果>
```

CXY 在 **24 小时内**在同一行补裁定，不开会、不多轮往返。
