# WGX Week 4 节点：Gradio 前端与交付体验

## WGX-N1：主题与布局精修

**目标**  
按展示稿统一浅色紫蓝主题、卡片、按钮、侧栏高亮和页面间距。

**输入**

- Week 3 四页集成版 UI。
- CXY-N1 最终 DoD 与展示稿说明。
- `layout.py`、主题配置与 Week 1 基础样式。

**工作**

- 统一顶栏、侧栏四项高亮、主区卡片和按钮样式。
- 对齐展示稿：浅色紫蓝、圆角卡片、情绪胶囊、波形区域（若已实现）。
- 检查四页标题、间距、对齐和字体层级一致。
- 环境状态区保持非导航项，样式与侧栏区分。
- 控制精修范围：超过 1 人日仍不稳定时，保信息层级，不换栈。

**输出**

- 更新后的 `layout.py` / 主题配置。
- 四页布局前后对比截图。

**三个指标**

- **哪些人的工作会影响我？** Week 3 页面是硬依赖；CXY-N1 视觉范围是软依赖。
- **我需要交付什么内容？** 主题代码和对比截图。
- **谁需要等待我完成该工作？** WGX-N3 等兼容测试；WGX-N4 等终稿截图。WGX-N2 可按既有页面并行检查四态。

**完成判定**

- 侧栏只有四项导航 + 环境状态，无第五页。
- 未引入积分、充值、真登录等展示稿外元素。

**AI 参考提示词**

```text
请精修Gradio四页布局与浅色紫蓝主题，对齐展示稿。

输入：<layout.py>、<四页模块>、<展示稿描述>

要求：
- 顶栏、侧栏高亮、卡片、按钮统一；
- 环境状态非导航；
- 四页间距与标题层级一致；
- 不增加新页面或SaaS元素；
- 1人日不稳定则保层级不换栈。

输出：修改清单、主题参数、对比截图位。
```

## WGX-N2：四态统一

**目标**  
补全并统一四页的空、加载、成功、失败状态展示。

**输入**

- Week 3 四页集成版 UI；WGX-N1 的主题精修是软依赖，收到后做最终样式对齐。
- CXY-N1 验收清单中的四态要求。
- LHY-N1 失败提示文案。

**工作**

- 逐页检查：音频、音色、合成、结果四页的四态组件。
- 统一加载指示、成功反馈、失败 `AppError` 展示样式。
- 补全空状态：无音色、无历史、无数据集等。
- 确认跨页操作（带入、跳页、复用）在四态下行为合理。
- 收集每页至少 1 组四态截图。

**输出**

- 四态统一说明（每页 4 态定义）。
- 16 张目标截图（4 页 × 4 态，可合并部分态）。
- 小型 UI 修复提交。

**三个指标**

- **哪些人的工作会影响我？** Week 3 页面是硬依赖；WGX-N1 主题与 LHY-N1 失败文案是软依赖，可先完成状态定义和组件检查。
- **我需要交付什么内容？** 四态说明、截图和 UI 修复。
- **谁需要等待我完成该工作？** WGX-N3/N4；CXY-N3 等页面证据。

**完成判定**

- 失败态展示真实错误，非 generic "Error"。
- 空状态有引导文案，非空白页。

**AI 参考提示词**

```text
请统一Gradio四页的空/加载/成功/失败四态。

输入：<audio/voice/tts/result_page>、<AppError展示方式>

每页定义：空态文案、加载指示、成功反馈、失败展示。
补全无音色、无历史、无数据集空状态。
输出：四态规范、待修清单、截图命名规则。
禁止假加载条或假成功动画。
```

## WGX-N3：浏览器兼容与播放下载

**目标**  
在 Windows 目标浏览器上验证 WAV 播放、下载和核心交互。

**输入**

- WGX-N2 四态统一版。
- LHY-N3 全新实例（或联调版）。
- CXY-N1 浏览器验收要求。

**工作**

- 在目标浏览器（如 Chrome/Edge）完整走通：试听、合成、结果播放、历史下载。
- 记录不兼容问题：播放器、下载命名、侧栏切换、长文本布局。
- 修复 UI 层阻断问题；后端问题退回 LHY。
- 输出浏览器测试报告与复现步骤。

**输出**

- 浏览器兼容测试报告。
- 播放/下载成功截图或短视频。
- UI 阻断修复列表。

**三个指标**

- **哪些人的工作会影响我？** WGX-N1/N2 和 LHY 集成版是硬依赖。
- **我需要交付什么内容？** 测试报告、截图和修复列表。
- **谁需要等待我完成该工作？** WGX-N4 等录屏；CXY-N4 等终审。

**完成判定**

- 目标浏览器可完成播放与下载，非仅开发浏览器可用。
- 每个兼容问题有浏览器版本与环境记录。

**AI 参考提示词**

```text
请生成Week 4浏览器兼容测试清单（Windows Chrome/Edge）。

范围：四页切换、试听播放、合成、结果播放、WAV下载、历史操作、跨页复用。

输出：步骤、期望、实际、浏览器版本、截图位、阻断/非阻断判定。
UI问题WGX修，服务问题转LHY。
```

## WGX-N4：录屏支持与终稿截图

**目标**  
配合 CXY 分镜完成演示录屏，并整理答辩用终稿截图集。

**输入**

- CXY-N2 演示脚本与分镜。
- WGX-N1/N2/N3 稳定 UI。
- LJQ-N1 演示参数包。
- LHY-N3 可演示实例。

**工作**

- 按分镜录制演示视频素材（或完整 8–10 分钟成片，由 CXY 剪辑亦可）。
- 确保录屏中操作与口播脚本一致，不出现未实现功能。
- 整理终稿截图：首页、四页主流程、四态代表、环境状态、失败示例（可选）。
- 标注录屏中需打码或裁剪的内容（路径、个人信息）。
- 配合彩排修正机位、分辨率和字体大小问题。

**输出**

- 录屏素材或成片路径。
- 终稿截图包（命名规范 + 用途说明）。
- 录屏问题与重录清单。

**三个指标**

- **哪些人的工作会影响我？** CXY-N2 是硬依赖；WGX-N1/N2/N3 是硬依赖。
- **我需要交付什么内容？** 录屏素材/成片、截图包和问题清单。
- **谁需要等待我完成该工作？** CXY-N4 等终审与答辩材料定稿。

**完成判定**

- 录屏主链路可在全新实例复现。
- 截图与最终 UI 一致，非早期草稿。

**AI 参考提示词**

```text
请根据以下演示分镜生成录屏执行清单与终稿截图清单：
<粘贴CXY-N2分镜>

输出：
1. 逐步录屏操作（窗口、分辨率、隐藏路径）；
2. 必拍截图列表与文件名；
3. 口播与画面同步检查点；
4. 重录触发条件；
5. 与未实现功能/夸大文案的审查点。

禁止录屏中使用假数据或Mock成功。
```
