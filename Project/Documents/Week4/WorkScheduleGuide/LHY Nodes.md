# LHY Week 4 节点：Python 业务与稳定性

## LHY-N1：典型失败处理加固

**目标**  
确保五类典型失败有明确、可读的用户提示，且不产生假成功状态。

**输入**

- Week 3 集成版 services 与 `AppError` 体系。
- CXY-N1 五类失败清单。
- Week 1–3 失败用例与 LJQ 失败场景表。

**工作**

- 加固并验证以下路径的用户提示与日志：
  1. 未授权 / 授权未确认；
  2. 音频无效（格式、时长、路径）；
  3. ASR 失败（可降级为手工输入，但不假转写）；
  4. 模型未加载 / 引擎离线；
  5. 显存不足 / 超时 / GPU 忙碌。
- 确认失败合成、失败试听、失败保存均不写成功历史或正式档案。
- 确认 JSON 损坏时重建策略仍不清空用户数据。
- 为每项补充或更新最小复现步骤，供 CXY 演示。

**输出**

- 五类失败加固清单（代码位置 + 提示文案 + 日志样例）。
- 更新后的相关 service 代码。
- 人工演示步骤（每条 1 页）。

**三个指标**

- **哪些人的工作会影响我？** Week 3 集成版是硬依赖；CXY-N1 失败清单是软依赖。
- **我需要交付什么内容？** 加固清单、代码更新和演示步骤。
- **谁需要等待我完成该工作？** CXY-N4 等失败验收；LHY-N2/N3 等测试与全新实例。

**完成判定**

- 五类失败均可人工触发且 UI 可见提示。
- 无 Mock 成功或静默失败。

**AI 参考提示词**

```text
请对照Week 3 services与CXY五类失败清单，加固AppError与用户提示。

范围：
未授权、音频无效、ASR失败、模型未加载、OOM/超时/GPU忙碌。

要求：
- 统一AppError code与gr.Error展示；
- 失败不写success历史/档案；
- JSON损坏重建不清空数据；
- 每项给复现步骤。

输出：修改点列表、提示文案、日志样例。
禁止假转写、假成功状态。
```

## LHY-N2：测试补全与 GPU 标记

**目标**  
补全相关 pytest，区分 GPU 测试与普通单测，形成可提交的报告。

**输入**

- LHY-N1 加固后的 services。
- Week 1–3 已有测试与 `contract-v2.0`。
- CXY-N1 最终 DoD 测试要求。

**工作**

- 补全/修复：`audio_service`、`voice_service`、`tts_service`、`history_service` 相关单测。
- 覆盖：路径校验、授权、原子 JSON、失败不写成功、索引重建。
- GPU 集成测试单独标记（如 `@pytest.mark.gpu`），与 CI/本地默认分离。
- 运行全量测试，记录通过/失败/跳过数量与环境。
- 修复阻断测试；非阻断失败记入问题单。

**输出**

- 测试报告（含命令、环境、结果摘要）。
- 新增/更新的测试文件列表。
- GPU 测试运行说明。

**三个指标**

- **哪些人的工作会影响我？** LHY-N1 是软依赖；Week 3 代码基线是硬依赖。
- **我需要交付什么内容？** 测试报告、测试代码和 GPU 运行说明。
- **谁需要等待我完成该工作？** LHY-N3 等全新实例前测试绿；CXY-N3/N4 等质量证据。

**完成判定**

- 相关 pytest 通过（或失败项有书面原因与修复计划）。
- GPU 测试未与默认单测混跑未标记。

**AI 参考提示词**

```text
请为Week 4补全services层pytest并分离GPU测试。

输入：<services目录>、<contract-v2.0>、<现有测试>

覆盖：
路径/授权、原子JSON、失败不写success、history/voices重建、AppError。

输出：
1. 缺失测试清单；
2. @pytest.mark.gpu 集成测试；
3. 运行命令与报告模板；
4. 已知flaky项说明。

禁止跳过断言或Mock GPU成功。
```

## LHY-N3：全新实例全流程验证

**目标**  
停止旧服务后，以干净进程完整走通产品主链路并记录证据。

**输入**

- LHY-N1/N2 加固与测试通过版本。
- CXY-N2 演示脚本主流程。
- LJQ-N1 演示参数包。

**工作**

- 终止所有旧 Gradio / GPU 占用进程。
- 全新启动 `app.py`，按 10 步演示链路执行一遍。
- 记录启动命令、环境变量、日志、生成的 WAV/JSON 路径。
- 执行重启验证：音色与历史恢复。
- 在目标浏览器验证播放与下载（与 WGX 协同）。
- 输出阻断/非阻断问题给 CXY 排期。

**输出**

- 全新实例验证记录（逐步 + 时间戳）。
- 主链路日志包。
- 问题清单。

**三个指标**

- **哪些人的工作会影响我？** LHY-N1/N2 是硬依赖；CXY-N2 脚本与 LJQ-N1 参数是软依赖。
- **我需要交付什么内容？** 验证记录、日志和问题清单。
- **谁需要等待我完成该工作？** CXY-N4 等终审；WGX-N3 等浏览器协同。

**完成判定**

- 验证在全新进程完成，非热补丁后未重启的“假全新”。
- 主链路每步有对应文件或截图证据。

**AI 参考提示词**
