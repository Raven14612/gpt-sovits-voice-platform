# 轻量级语音克隆项目当前执行计划 v4

> 生效日期：2026-09-04  
> 本版重点：50 系主线优先；40 系验证降为非阻塞增强；LHY 改为离线后端支援。
> 项目形态：学生团队、本地 Windows GPU、Gradio 单体应用  
> 主验证设备：CXY 的 RTX 5060 Laptop GPU  
> 40 系观察设备：LJQ 可提供一台 RTX 40 系代表机；40 系验证不是 MVP 阻断条件

## 1. 项目结论

本项目不拥有 GPT-SoVITS 或任何第三方整合包。项目开发内容是：

```text
自研 Gradio UI
→ 自研 Python services、数据档案、任务状态和错误处理
→ 自研 GPT-SoVITS 适配器
→ 用户在本机单独准备的 GPT-SoVITS 运行环境
```

第三方整合包只用于快速了解输入、输出、参数和运行链路，不复制进入项目仓库，不宣称为自研，也不在业务代码中写死其目录。

## 2. MVP 路线

主路线：

```text
导入授权音频
→ 固定参数切分
→ FunASR 中文识别
→ 人工校对文本与人工情绪标签
→ 特征提取
→ SoVITS 与 GPT 固定参数微调
→ 保存音色档案及一对权重
→ 串行加载并合成
→ 播放、下载、历史管理
```

保底路线：合格的 3–10 秒音频 + 准确参考文本，可绕过训练，直接做零样本合成。保底路线用于环境不支持训练时维持产品可用性，但不能冒充完成了微调训练。

MVP 情绪只做人工标签和人工参考片段。标签为 `neutral`、`happy`、`sad`；默认 `neutral`。未来可让 LLM 给出可修改建议，但不进入当前验收。

## 3. 固定技术边界

- 唯一入口为 `Project/app.py`，使用 Gradio Blocks。
- 不增加 Vue、React、FastAPI、数据库、Redis、Celery 或云服务。
- UI/业务 Python 与模型运行时分离；模型任务通过配置后的解释器和适配脚本执行。
- GPU 任务全局串行；关闭并行推理，禁止同时训练和推理。
- 不修改 GPT-SoVITS 核心模型代码来赶工。
- 不承诺支持所有 NVIDIA GPU，只对有真实证据的轨道作兼容声明。
- 不实现水印、敏感词系统、登录、积分、充值、音色市场或公网分享。

## 4. 四页产品结构

| 页面 | MVP 职责 |
|---|---|
| 音频数据处理 | 上传、播放器、首尾裁剪、固定参数切分、ASR、文本校对、人工情绪标签 |
| 音色训练与仓库 | 选择数据集、显示训练阶段、保存音色名称与权重档案、删除/查看音色 |
| 文本生成语音 | 选择音色、输入文本、选择可用情绪、串行合成、高级语速/停顿 |
| 合成结果管理 | 播放、下载、查看历史、复用参数、删除结果 |

运行时侧栏一次只显示一个完整页面。环境状态放在侧栏底部，不作为第五页。

## 5. 团队职责与决策权（v4：50 系主线优先）

项目采用“50 系核心主线 + 非阻塞支援”安排。只有 CXY 的 50 系真实运行结果会阻塞 MVP；LHY、WGX、LJQ 的任务都必须做成可独立交付、可延后合并的模块。

### CXY：50 系主线负责人和最终整合人

- 唯一负责 50 系整合包的真实操作、训练/推理证据、参数冻结和最终 Demo。
- 根据 Web UI 证据决定 adapter 需要接哪些真实入口；必要时亲自完成最后的主线联调。
- 负责产品范围、验收结论、第三方边界和最终合并。
- 不再承诺同时完成所有页面细节；只保证主线能跑通。

### LHY：离线后端与工程支援负责人（不依赖整合包）

- 专门完成不需要安装 GPT-SoVITS、不需要 GPU 的工作：schemas、AppError、数据校验、JSON 索引、任务状态机、串行锁、日志、错误转换、配置读取、测试和文档。
- 先用测试替身验证服务和 adapter 的输入输出；不负责在自己的 40 系机器上复现模型，不等待真实 WAV。
- 只预留清晰的 adapter 接口和子进程调用边界；真实命令由 CXY 提供后再做小范围接线。
- 不把测试替身、页面按钮或计划文字写成模型成功。

### WGX：低耦合 UI 交付人（不参与模型联调）

- 只交付四页 UI、导航、State、状态组件、错误提示和浏览器冒烟检查。
- 页面只调用 services 接口；使用空状态和明确的“未接入”提示，不等待 CXY，也不依赖整合包。
- 不负责真实模型命令、GPU 调试、adapter 兼容和最终联调。页面模块完成后直接交付，CXY 可按主线需要取用。

### LJQ：40 系可选观察员（不阻塞 MVP）

- 优先提交 40 系环境基线和 Web UI 运行观察记录。
- 40 系项目 adapter 复现、零样本推理和训练属于可选增强；没有结果时只记录“未验证/阻塞原因”。
- 不修改主线代码，不要求 CXY 等待，不以 40 系结论否定 50 系主线。

### 主线依赖和兜底规则

```text
CXY 50 系真实链路 ─────┐
                       ├─> 50 系 MVP 验收
LHY 离线后端/测试 ─────┘

WGX UI ───────────────> 可后合并，不阻塞模型验证
LJQ 40 系观察 ─────────> 可选报告，不阻塞 MVP
```

- CXY 只需要等待 LHY 的接口和自己的 50 系真实证据；不等待 LJQ 或 WGX。
- LHY 交付接口和测试替身后，CXY 可以用最小临时 UI/现有页面完成主线验证；WGX 页面晚到不构成阻塞。
- WGX 或 LJQ 未交付时，不追着补做对方全部工作；在交接表中记为“非阻塞延期”。
- 任何人提交的模拟结果只能用于开发测试，不能替代 CXY 的 50 系真实 WAV、权重和日志。

## 6. 四周执行安排

### Week 1：50 系主线取证、离线后端和 UI 壳

**CXY**

- 先用 50 系整合包 Web UI 生成一条新的真实 WAV，补齐权重加载证据；再根据页面、源码和日志反查 adapter 调用。
- 固定 50 系整合包的探测、切分、ASR、训练、推理命令和 I/O；无法从现有证据确认的项目标记“待实测”，不猜命令。
- 审核并冻结 `engine-adapter-v0.1`。

**LHY**

- 完成 `schemas.py`、`AppError`、service 模块、任务状态机、JSON 索引、日志和无 GPU 测试。
- 只保留 adapter 接口和配置读取骨架；不在本机安装或运行整合包。

**LJQ**

- 提交一份 40 系环境/Web UI 观察记录即可；adapter 复现和真实 WAV 属于可选增强。
- 不修改主线代码，不阻塞 CXY。

**WGX**

- 完成四页工程壳、侧栏切换、共享 State 和五种视觉状态；作为独立 UI 交付，不等待模型。

**Week 1 过线**

- 50 系通过整合包 Web UI 产生真实 WAV，并提交页面、日志、文件证据；随后由 CXY 决定是否做项目 adapter 复现。
- LHY 的后端接口可导入、可测试，路径没有写死，且不依赖整合包。
- WGX 四页可切换且不依赖 GPU 开发。
- LJQ 有 40 系观察记录即可；没有 40 系推理不影响 Week 1 过线。

### Week 2：数据处理与训练任务

**CXY**：冻结切分、ASR、特征提取、SoVITS/GPT 训练参数；运行一次 50 系完整训练闭环。  
**LHY**：实现数据集档案、训练编排、日志、权重归档、恢复和原子索引；使用测试替身，不在本机跑整合包。  
**LJQ**：有时间再完成 40 系项目内零样本推理；可选验证缩小训练任务，不作为 MVP 依赖。  
**WGX**：完成音频页和音色训练页，显示真实阶段而非虚构百分比。

**Week 2 过线**：50 系从数据集产生可加载的 GPT/SoVITS 权重；项目正确保存音色档案。40 系训练不是阻断项。

### Week 3：合成、情绪参考与结果闭环

**CXY**：验证训练权重、中性与人工情绪参考，执行连续合成回归。  
**LHY**：完成串行 TTS、历史、复用、失败隔离和索引恢复；真实模型调用等 CXY 提供证据后再接线。  
**LJQ**：有条件再在 40 系通过项目入口真实合成，记录显存和失败条件；不阻塞主线。  
**WGX**：完成合成页、结果页、情绪置灰、历史复用和删除。

**Week 3 过线**：优先形成“50 系音色 → 合成 → 结果”的真实闭环；历史、复用和重启恢复由 LHY/现有 UI 逐步补齐，不得反过来阻塞首次出声。

### Week 4：稳定性、兼容结论与答辩

**CXY**：最终验收、范围冻结、主 Demo 和证据索引。  
**LHY**：错误加固、日志、测试、安装与配置说明。  
**LJQ**：提交 40 系兼容报告和备用证据。  
**WGX**：视觉精修、浏览器兼容、截图、录屏和操作说明。

## 7. 兼容性声明分级

| 声明 | 必须具备的真实证据 |
|---|---|
| 50 系完整支持 | 数据处理、训练、权重加载和合成均在代表机真实通过 |
| 40 系推理兼容 | 至少一台 40 系通过项目入口真实合成 |
| 40 系训练兼容 | 至少一台 40 系完成训练并加载新权重合成 |

MVP 最低只要求第一项（50 系完整支持）。如果同时完成前两项，对外可以补充 40 系推理兼容；如果只完成第一项，对外统一表述为：

> 项目已在 RTX 50 系验证完整训练与推理闭环；40 系兼容仍在实验性验证中。

## 8. 统一交接格式

每次交接只发：

```text
[任务ID]
产物：<仓库路径>
证据：<日志/音频/截图路径>
结论：通过 / 部分通过 / 阻塞
已知限制：<一至三条>
下游可开始：<任务ID或无>
```

任务超过 1.5 人日仍无最小产物时，必须拆分；阻塞超过半天写入 `Decisions.md`，由对应领域负责人提出处理方案，CXY裁定范围与最终验收影响。
