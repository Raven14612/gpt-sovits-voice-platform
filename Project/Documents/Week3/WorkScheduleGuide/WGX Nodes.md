# WGX Week 3 节点：Gradio 前端与体验

## WGX-N1：文本生成语音页

**目标**  
完成音色选择、文本输入、情绪胶囊、高级设置和合成状态的页面交互。

**输入**

- Week 1 `tts_page.py` 空壳与 `layout.py`。
- CXY-N1 合成页字段和 DoD。
- LJQ-N1/N2 合成参数与情绪置灰规则。
- LHY-N1 `tts_service` 说明。

**工作**

- 在音色页增加条件性的“追加情绪参考”入口：选择已有音色、情绪标签、同说话人授权音频、准确参考文本和语种；无合法素材或接口未就绪时隐藏/禁用，不阻断中性主流程。
- 实现文本框与 `0/500` 计数（500 为可配置演示上限）。
- 实现语种选择与音色下拉（读取 `list_voices`，无效音色不显示）。
- 实现情绪胶囊：中性、开心、悲伤；无 `emotion_refs` 时置灰。
- 高级设置默认折叠：语速、停顿（`speed_factor`、`fragment_interval`）。
- 合成按钮：提交后禁用、显示 queue/执行状态；失败展示 `AppError`。
- 合成成功触发跳页事件（具体绑定在 WGX-N3/LHY-N4）。
- 四态截图：空、加载、成功、失败。

**输出**

- `tts_page.py` 交互版。
- 音色页情绪参考追加入口及其启用/隐藏规则。
- 情绪置灰与高级设置说明。
- 事件绑定清单与截图。

**三个指标**

- **哪些人的工作会影响我？** Week 1 页面骨架是硬依赖；CXY-N1、LJQ-N1/N2、LHY-N1 是软依赖，可先搭控件，收到字段后对齐。
- **我需要交付什么内容？** 合成页、可选情绪参考入口、置灰规则说明、事件清单和截图。
- **谁需要等待我完成该工作？** WGX-N3 等跳页 State；LHY-N4 等事件名称；CXY-N4 等页面证据。

**完成判定**

- 无音色时下拉为空或有明确空状态。
- 缺情绪参考时对应胶囊不可选。
- 只有 `add_emotion_reference` 成功并刷新音色档案后，对应情绪胶囊才可启用。
- 不使用假进度或假 WAV。

**AI 参考提示词**

```text
请实现Week 3 Gradio tts_page并预留绑定tts_service。

包含：
- 文本框与0/500计数；

- 情绪胶囊与emotion_refs置灰规则；
- 折叠高级设置：语速、停顿；
- 合成按钮四态、防重复提交UI；
- AppError展示；
- 合成成功输出跳页信号（State/event）。

契约：<粘贴tts部分>
LJQ规则：<粘贴情绪映射>
不实现历史列表、不放假合成成功。
```

## WGX-N2：合成结果管理页

**目标**  
完成当前结果展示、历史列表、播放、下载、复用和删除交互。

**输入**

- Week 1 `result_page.py` 空壳。
- CXY-N1 结果页字段。
- LHY-N2 `history_service` 说明。

**工作**

- 当前结果区：波形或播放器、进度、时长。
- 快捷操作：播放、下载 WAV；“分享”仅导出本地文件，无公网链接。
- 历史列表：时间倒序，显示文本摘要、音色、情绪、语速、时长、创建时间。
- 每条历史：播放、下载、复用、删除。
- “清空记录”二次确认（若本周 scope 包含；否则单条删除为主）。
- 空状态：无历史时的提示。
- 四态截图。

**输出**

- `result_page.py` 交互版。
- 历史项组件与操作说明。
- 截图。

**三个指标**

- **哪些人的工作会影响我？** Week 1 页面骨架是硬依赖；CXY-N1 与 LHY-N2 是软依赖，收到后对齐。
- **我需要交付什么内容？** 结果页、操作说明和截图。
- **谁需要等待我完成该工作？** WGX-N3 等复用跳页；LHY-N4 等事件名称。

**完成判定**

- 历史项字段与 `GenerationRecord` 一致。
- 删除操作有确认，不静默删。

**AI 参考提示词**

```text
请实现Week 3 Gradio result_page并预留绑定history_service。

包含：
- 当前结果播放器；
- 播放、下载WAV、本地导出（非公网分享）；
- 历史倒序列表与摘要字段；
- 播放、下载、复用、删除；
- 清空或批量删除的二次确认；
- 空状态与AppError；
- 复用输出跳回合成页信号。

契约：<粘贴history部分>
不展示失败合成为成功项、不放假历史。
```

## WGX-N3：跨页跳页与复用 State

**目标**  
完成保存音色刷新下拉、合成成功切结果页、历史复用回填合成页。

**输入**

- WGX-N1 合成页。
- WGX-N2 结果页。
- Week 2 跨页 State 经验。
- LHY-N2 复用字段与 LHY `list_voices` 刷新时机。

**工作**

- 定义并文档化 `synth_state`：文本、语种、voice_id、emotion、speed、fragment_interval、last_result_id。
- 音色页保存成功 → 刷新合成页音色下拉与卡片（若同屏可见）。
- 合成成功 → 切到结果页并加载当前 WAV。
- 历史“复用” → 切到合成页并回填全部参数。
- 删除音色或结果 → 同步更新相关下拉/列表（与 LHY 索引一致）。
- 流程截图：刷新、跳页、回填。

**输出**

- 跨页事件与 State 文档。
- `synth_state` 字段说明。
- 跳页与复用流程截图。

**三个指标**

- **哪些人的工作会影响我？** WGX-N1/N2 是硬依赖；LHY-N2 是软依赖，收到复用字段后对齐。
- **我需要交付什么内容？** 跨页事件、State 文档和流程截图。
- **谁需要等待我完成该工作？** LHY-N4 与 WGX-N4 硬等待；CXY-N4 等跨页证据。

**完成判定**

- 复用后合成页字段与历史记录一致。
- 合成成功必定切到结果页（除非用户手动切走，需记录 UX 决策）。

**AI 参考提示词**

```text
请设计Week 3 Gradio跨页State与事件。

场景：
1. 保存音色→刷新合成页下拉；
2. 合成成功→切结果页并显示当前WAV；
3. 历史复用→切合成页并回填text/voice/emotion/高级参数；
4. 删除音色/结果→同步UI。

输入：<tts_page>、<result_page>、<voice_page>、<contract-v2.0跨页表>

输出：State字段、事件名、触发条件、截图清单。
不实现Week 4主题精修。
```

## WGX-N4：浏览器联调与四页闭环

**目标**  
在集成版上完成合成链路浏览器测试并收集证据。

**输入**

- LHY-N4 集成版。
- WGX-N1/N2/N3。
- CXY-N2 失败用例。

**工作**

- 浏览器走通：选音色 → 合成 → 结果页 → 复用 → 再合成。
- 验证保存音色后合成下拉即时更新。
- 验证情绪置灰与有样本时的切换 UI。
- 验证失败提示、按钮恢复和历史不被污染。
- 按 CXY 用例抽查 3–5 条失败路径。
- 收集截图、短视频或操作记录；只修 UI 阻断，不提前做 Week 4 视觉精修。

**输出**

- 浏览器联调记录。
- 合成/结果/跨页截图。
- UI 阻断问题清单。

**三个指标**

- **哪些人的工作会影响我？** LHY-N4 是硬依赖；WGX-N1/N2/N3 是硬依赖。
- **我需要交付什么内容？** 联调记录、截图和问题清单。
- **谁需要等待我完成该工作？** CXY-N4 等页面证据；LHY 等 UI 阻断修复。

**完成判定**

- 主流程可在目标浏览器完成。
