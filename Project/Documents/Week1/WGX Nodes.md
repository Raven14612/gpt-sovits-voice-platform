# WGX Week 1 节点：Gradio 前端与体验

## WGX-N1：建立页面信息架构

**目标**  
固定展示稿在 Gradio 中的正确结构，避免误做四页同屏。

**输入**

- CXY-N1 导航文案。
- 最终页面展示稿。
- 总计划页面边界。

**工作**

- 建立顶栏、四项导航、环境状态和右侧容器。
- 环境状态只作为侧栏信息，不是第五页。
- 定义组件名称和基础布局。

**输出**

- `layout.py` 静态结构。
- 页面组件清单。
- 展示稿元素保留/删除说明。

**三个指标**

- **哪些人的工作会影响我？** CXY-N1 是软依赖；可先用总计划中的四页名称，收到冻结文案后再对齐。
- **我需要交付什么内容？** `layout.py` 静态结构、组件清单和展示稿取舍说明。
- **谁需要等待我完成该工作？** WGX-N2 硬等待；LHY-N4 软等待模块导入方式。

**完成判定**

- 侧栏只有四项。
- 主区按单页显示设计，不是 2×2。

**AI 参考提示词**

```text
请用Gradio Blocks设计layout.py骨架。

必须包含：
- 顶栏“AI音频生成”、帮助、设置、本地用户；
- 左侧四项：音频数据处理、音色样本克隆、文本生成语音、合成结果管理；
- 侧栏底部环境状态；
- 右侧单页内容容器。

运行时一次只显示一个页面；展示稿2×2只是总览。
不实现积分、充值、真实登录、第五页或Vue/React。
输出组件层级、elem_id建议和代码草案。
```

## WGX-N2：建立四页空壳与基础主题

**目标**  
建立正确控件位置，但不提前实现 Week 2/3 业务。

**输入**

- WGX-N1 布局。
- CXY-N2 契约字段；未交付时可占位，收到后对齐。
- 最终展示稿。

**工作**

- 建立四页模块和空状态。
- 音频页：上传/波形/切分/转写占位。
- 音色页：生成/保存/卡片墙占位。
- 合成页：文本/音色/情绪/高级设置占位。
- 结果页：波形/历史占位。
- 建立基础浅色紫蓝 CSS。

**输出**

- 四个页面文件。
- `theme.css` 基础版。
- 空状态截图。

**三个指标**

- **哪些人的工作会影响我？** WGX-N1 是硬依赖；CXY-N2 是软依赖，可先用占位字段，收到契约后对齐。
- **我需要交付什么内容？** 四页空壳、基础主题和空状态截图。
- **谁需要等待我完成该工作？** WGX-N3 硬等待。

**完成判定**

- 四页都有清楚空状态。
- 没有固定假音频、假进度或假音色卡。

**AI 参考提示词**

```text
请起草四个独立Gradio页面空壳：
- audio_page：上传、波形、裁剪、切分列表、转写；
- voice_page：参考音频、生成试听、保存、卡片墙；
- tts_page：文本、语种、音色、情绪、高级设置、合成；
- result_page：当前波形、播放下载、历史与复用。

要求：
- 只做控件和空状态，不实现Week 2/3业务；
- 主区一次显示一个页面；
- 浅色紫蓝CSS；
- 不放假音频、假音色或假成功；
- 字段名与契约一致：<粘贴契约>。
```

## WGX-N3：页面切换与共享状态

**目标**  
完成侧栏切换和后续跨页状态容器。

**输入**

- WGX-N2 四页模块。
- LHY-N2 schema说明；属于软依赖。

**工作**

- 侧栏控制四页 `visible`。
- 当前项高亮。
- 建立 `selected_slice`、`draft_voice`、`last_tts_params`、`current_result` 等 `gr.State` 占位。
- 环境状态保持只读。

**输出**

- 可独立验证的页面切换。
- 共享状态定义。
- 交给 LHY-N4 的 UI 模块。

**三个指标**

- **哪些人的工作会影响我？** WGX-N2 是硬依赖；LHY-N2 是软依赖，收到 schema 后核对 State 字段。
- **我需要交付什么内容？** 页面切换、共享 State 和 UI 模块说明。
- **谁需要等待我完成该工作？** LHY-N4 硬等待；WGX-N4 等集成版本。

**完成判定**

- 点击四项时主区始终只显示一页。
- State 不包含虚构业务结果。

**AI 参考提示词**

```text
请在Gradio Blocks中实现四页侧栏切换。

输入：layout.py与四个页面构建函数。
要求：
- 四项导航控制四个gr.Group或gr.Column的visible；
- 当前项高亮；
- 默认显示音频数据处理；
- gr.State包含selected_slice、draft_voice、last_tts_params、current_result；
- 环境状态不是第五页；
- 不实现音频业务，不写假输出。

请给出事件绑定和人工浏览器验证清单。
```

## WGX-N4：浏览器联调与四态

**目标**  
修复影响阶段 Demo 的页面问题。

**输入**

- LHY-N4 一键启动集成版。
- WGX-N3 页面模块。

**工作**

- 在 Chrome/Edge 检查启动和四页切换。
- 补充空、加载、成功、失败状态的基础样式。
- 检查高亮、布局和控制台错误。
- 只修阻断问题，不增加新功能。

**输出**

- 浏览器冒烟结果。
- 页面截图。
- 修复后的 UI 模块。

**三个指标**

- **哪些人的工作会影响我？** LHY-N4 是硬依赖；只有集成版可启动后才能进行完整浏览器联调。
- **我需要交付什么内容？** 浏览器检查表、截图和 UI 阻断修复。
- **谁需要等待我完成该工作？** CXY-N3 等最终页面证据。

**完成判定**

- 四项导航可点击且无白屏。
- 页面无明显错位；错误态不显示假成功。

**AI 参考提示词**

```text
请生成Week 1 Gradio浏览器冒烟和四态检查清单。

检查：
- app.py启动；
- 顶栏和侧栏；
- 四项逐一切换且主区一次一页；
- 环境状态不是第五页；
- 空、加载、成功、失败状态；
- Chrome/Edge控制台和布局问题。

只修UI阻断，不修改业务，不增加功能，不加入假音频。
```
