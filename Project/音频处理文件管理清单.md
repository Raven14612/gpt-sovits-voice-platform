# 音频处理文件管理清单

本清单对应项目页面的长音频处理流程（2026-09-10 更新）。项目产生的文件和索引均使用相对于部署根目录的路径；程序启动时将这些路径解析为当前根目录。只有运行时配置中的外部引擎位置由 `engine.local.json` 提供。

## 文件流向

| 阶段 | 文件类型 | 存放位置 | 说明 |
|---|---|---|---|
| 原始输入 | 用户授权 PCM WAV | `data/datasets/<dataset-id>/source.wav` | 导入完整原音频副本；默认保留到结尾，外部原件只读 |
| 处理参数 | `input.json` | `data/datasets/<dataset-id>/processing/<task-id>/` | 记录原路径、起止采样点、任务和数据集 ID |
| 范围裁剪 | `input.wav` | 同上 | 仅用户指定保留范围时产生；完整音频直接送入切分 |
| 语音切分 | 短 WAV 切片 | `data/datasets/<dataset-id>/processing/<task-id>/slices/` | 调用整合包真实切分脚本；不固定只取 5 秒 |
| ASR 识别 | `slices.list` | `data/datasets/<dataset-id>/processing/<task-id>/asr/` | 对全部切片运行 FunASR；通过一一对应检查后更新数据集 |
| 处理日志 | 切分和 ASR 日志 | `data/logs/audio/<task-id>-slicing.log`、`<task-id>-asr.log` | 每个阶段结束时保存完整命令、工作目录、退出码、标准输出和错误 |
| 项目导入 | 数据集索引 | `data/index/datasets.json` | 保存数据集 ID、名称、有效路径和状态 |
| 文本校对 | `corrected.list` | `data/datasets/<revision-uuid>/corrected.list` | 现有校对服务为每次保存建立独立版本目录；具体位置以索引为准 |
| 情绪标签 | `emotions.json` | 与 `corrected.list` 同目录 | 只允许 `neutral`、`happy`、`sad`；自动识别不等于人工确认 |
| 特征提取 | BERT/HuBERT/SV/语义特征 | `data/datasets/<dataset-id>/features/<task-id>/` 下的 `3-bert/`、`4-cnhubert/`、`5-wav32k/`、`7-sv_cn/`、`2-name2text.txt`、`6-name2semantic.tsv` | 训练页独立“提取特征（不训练）”按钮，只处理已校对数据集 |
| 特征溯源 | `input.list`、`manifest.json` | 同一特征任务目录 | 固定本次文本副本，记录原输入 SHA-256、输出大小、数据集及任务 ID；改动校对后旧特征引用失效 |
| 特征日志 | 四个子阶段日志 | `data/logs/features/<task-id>-feature_text.log`、`-feature_hubert.log`、`-feature_sv.log`、`-feature_semantic.log` | v2Pro 的 SV 单独记录；子进程全部串行 |
| 训练日志 | 文本日志和配置 | 整合包 `logs/<name>/`；项目编排日志在 `data/logs/training/` | 新训练暂缓，本次不产生 |
| 训练权重 | `.ckpt`、`.pth` | 项目归档目录 `data/voices/<voice-id>/`；外部整合包目录只由运行时配置定位 | 后续真实训练成功且权重变化后方可归档 |
| 合成结果 | WAV 和日志 | `data/outputs/` | 项目合成服务输出，本次不产生 |
| 任务索引 | JSON | `data/index/tasks.json` | 保存 pending/running/succeeded/failed/cancelled 状态 |
| 音色索引 | JSON | `data/index/voices.json` | 记录已验证音色及相对权重路径 |

## 路径规则

1. `data/index/*.json` 中的项目文件统一写成 `data/...`、`Documents/...` 等相对路径；读取时自动拼接部署根目录。
2. 任务日志路径统一写成 `data/logs/...`；页面显示同样使用相对路径。
3. `data/datasets` 内的 `.list` 文件第一列切片路径使用 `data/datasets/...` 相对路径，校验时按部署根目录解析。
4. 音色档案中的项目权重使用 `data/voices/...`；外部引擎已有权重可保留引擎内部相对名，由引擎配置解析，不写入个人绝对路径。
5. `engine.local.json` 是本机部署配置，不提交仓库；复制项目到另一台机器时只需重新填写 `engine_root` 和 `python_path`。

## 管理规则

1. 正式目录 `slicer_opt`、`asr_opt`、`logs/Citlali` 不覆盖。
2. 每次处理使用独立 `<task-id>` 目录；失败保留诊断文件，不替换数据集上次有效结果。重新处理成功后需重新人工校对。
3. 初始 ASR 文本不能直接视为人工校对结果；状态保持 `transcribed`，校对完成后才变为 `reviewed`。
4. 特征提取和训练前先检查输入 `.list`、切片数量和路径是否一致。
5. 训练未成功或权重未变化时，不创建 `verified` 音色档案。
